
### 📌 Return on Investment (ROI) Analysis

The current roll-call attendance process consumes approximately 10 minutes per class due to pronunciation challenges and manual recording. For an institution with 100 teachers conducting 5 classes a day over 20 days per month, this amounts to:

**1,667 hours/month lost to attendance**  
At an average hourly teacher rate of €30/hour, this equates to:  
**€50,010/month in lost productivity**

**Project Cost Breakdown:**
- Raspberry Pi Zero Kits + PoE Setup + NFC Readers: €1,035
- SD Cards, LEDs, Speakers, Mounting: €315
- Master Server & Network Equipment: €250
- Developer Setup (Apple): €299
- Miscellaneous: €200
- **Total Investment: €2,099**

**ROI:**
\[
	ext{ROI} = rac{50,010 - 2,099}{2,099} × 100 ≈ 2,284\%
\]

This means the system pays for itself in **under a single day of operation**.

### 🔁 80/20 Rule in Action
By prioritizing just 20% of the components — NFC tap, Pi-based device feedback, and database automation — the system delivers over 80% of the value, transforming attendance from a tedious process into a real-time, error-free task.
